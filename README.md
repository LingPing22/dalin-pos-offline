# Dalin POS Offline

ระบบขายหน้าร้านสำหรับ iPad ที่ **เก็บข้อมูลทั้งหมดไว้ในเครื่อง** ไม่มีเซิร์ฟเวอร์ ไม่ใช้ฐานข้อมูลบนเน็ต และ **ฝากไว้ฟรีบน GitHub Pages** (`ชื่อ.github.io`) เปิดได้ทุกเครื่องโดยไม่ต้องตั้ง DNS

- ใช้อินเทอร์เน็ตแค่ **ตอนเปิดครั้งแรก** หลังจากนั้นขายได้โดยไม่ต้องมีเน็ตเลย
- หน้าตาและการใช้งานเหมือน Dalin POS เวอร์ชันออนไลน์ทุกอย่าง (หน้าขาย, Dashboard กำไรสุทธิ, สินค้า, บิล, ค่าใช้จ่าย, ตั้งค่า)
- มีปุ่ม **สำรองข้อมูล / กู้คืน** ในหน้า ຕັ້ງຄ່າ

> ⚠️ ข้อมูลอยู่ใน iPad เครื่องเดียว ถ้าเครื่องหาย พัง หรือลบแอป ข้อมูลจะหาย **ต้องกดสำรองข้อมูลทุกสัปดาห์** แล้วส่งไฟล์ไปเก็บใน LINE หรือ Google Drive

---

## 1. อัปขึ้น GitHub Pages (ทำครั้งเดียว ~10 นาที)

### 1.1 สร้าง repo ใหม่บน GitHub
1. github.com → **+ → New repository**
2. ชื่อ: `dalin-pos-offline` เลือก **Public**
   (GitHub Pages ฟรีใช้ได้กับ repo แบบ Public — โค้ดไม่มีรหัสลับอะไร ข้อมูลร้านอยู่ใน iPad ไม่ได้อยู่ใน GitHub)
3. ไม่ต้องติ๊กอะไร → **Create repository**

### 1.2 อัปโหลดโค้ด
แตกไฟล์ zip แล้วเปิด Terminal ในโฟลเดอร์ `dalin-pos-offline`:

```bash
git init
git add .
git commit -m "Dalin POS Offline"
git branch -M main
git remote add origin https://github.com/LingPing22/dalin-pos-offline.git
git push -u origin main
```

### 1.3 เปิด GitHub Pages
1. ใน repo → **Settings → Pages**
2. **Source** เลือก **GitHub Actions**
3. ไปที่แท็บ **Actions** → จะเห็นงาน "Deploy to GitHub Pages" กำลังทำงาน (ถ้าไม่มี กด **Run workflow**)
4. รอจนขึ้น ✅ สีเขียว (~2 นาที)

ลิงก์ของร้านจะเป็น:

```
https://lingping22.github.io/dalin-pos-offline/
```

ทุกครั้งที่แก้โค้ดแล้ว `git push` → GitHub จะอัปเดตเว็บให้เอง และ iPad จะขึ้นปุ่ม “ມີເວີຊັນໃໝ່ — ແຕະເພື່ອອັບເດດ” (ข้อมูลในเครื่องไม่หาย)

---

## 2. ติดตั้งบน iPad ของร้าน

1. ต่อเน็ต (ครั้งแรกเท่านั้น) → เปิด **Safari** → ลิงก์ข้างบน
2. รอหน้าเลือกผู้ใช้ขึ้น → กด **Share → Add to Home Screen → Add**
3. **เปิดจากไอคอน Dalin POS เสมอ** (ข้อมูลในไอคอน กับใน Safari แยกกัน)
4. Login ด้วย PIN `1234` → แตะไปหน้าต่างๆ 1 รอบ (ระบบจะเก็บแอปไว้ในเครื่องทั้งหมด)
5. ทดสอบ: ปิด Wi-Fi → ปิดแล้วเปิดแอปใหม่ → ต้องใช้งานได้ปกติ

ตั้งค่า iPad เพิ่ม: **Auto-Lock → Never**, เปิด **Guided Access** ถ้าต้องการล็อกให้อยู่ในแอป

---

## 3. ก่อนเปิดร้านจริง (ในแอป)

- **ຕັ້ງຄ່າ → ຜູ້ໃຊ້**: เปลี่ยน PIN `1234` / `0000` / ชื่อผู้ใช้
- **ຕັ້ງຄ່າ**: ข้อมูลร้าน, VAT (ร้านเล็กที่ไม่ได้จด VAT ให้ปิด), % ค่าธรรมเนียม, QR รับเงิน, ขนาดกระดาษ → กด **ບັນທຶກການຕັ້ງຄ່າ**
- **ສິນຄ້າ**: ลบเมนูตัวอย่าง ใส่เมนูจริง พร้อม **ต้นทุน** (ใช้คิดกำไรสุทธิ) ถ่ายรูปจาก iPad ได้
- อยากโชว์ Dashboard ให้แม่ค้าดู: **ຕັ້ງຄ່າ → ໃສ່ຂໍ້ມູນຕົວຢ່າງ** → ดูเสร็จแล้วกด **ລຶບບິນ ແລະ ຄ່າໃຊ້ຈ່າຍທັງໝົດ** ก่อนขายจริง

---

## 4. สำรองและกู้คืนข้อมูล

**สำรอง** (แนะนำทุกสัปดาห์): ຕັ້ງຄ່າ → **ສຳຮອງຂໍ້ມູນ (ສົ່ງເປັນໄຟລ໌)** → เลือก LINE / Save to Files / Google Drive
Dashboard จะขึ้นแถบเตือนสีเหลือง ถ้าไม่ได้สำรองเกิน 7 วัน

**กู้คืน** (เช่น เปลี่ยน iPad ใหม่): ติดตั้งแอปในเครื่องใหม่ → Login `1234` → ຕັ້ງຄ່າ → **ກູ້ຄືນຈາກໄຟລ໌ສຳຮອງ** → เลือกไฟล์ → **ຢືນຢັນ**
(ข้อมูลในเครื่องจะถูกแทนที่ด้วยข้อมูลในไฟล์ทั้งหมด รวมถึง PIN)

## 5. สำหรับนักพัฒนา

```bash
npm install
npm run dev                                  # http://localhost:3000
NEXT_PUBLIC_BASE_PATH=/dalin-pos-offline npm run build   # ได้โฟลเดอร์ out/
npm test
```

| ไฟล์ | หน้าที่ |
|---|---|
| `src/lib/db.ts` | โครงสร้างฐานข้อมูลในเครื่อง (IndexedDB ผ่าน Dexie) |
| `src/lib/store.ts` | “หลังบ้าน” ทั้งหมด: login, สินค้า, บิล, ค่าใช้จ่าย, ตั้งค่า, สำรอง/กู้คืน |
| `src/lib/report.ts` | คำนวณ Dashboard + กำไรสุทธิ |
| `src/lib/pricing.ts` | คำนวณยอดรวม / ส่วนลด / VAT / ค่าธรรมเนียม |
| `scripts/build-sw.mjs` | สร้าง `sw.js` ที่เก็บทั้งแอปไว้ในเครื่อง (ใช้แบบ offline) |
| `.github/workflows/deploy.yml` | build และอัปขึ้น GitHub Pages อัตโนมัติ |

**ข้อจำกัด:** ใช้ได้ทีละเครื่อง (ไม่ sync ข้ามเครื่อง), ดูยอดจากนอกร้านไม่ได้ — ถ้าวันหลังต้องการ ให้ย้ายไปใช้ Dalin POS เวอร์ชันออนไลน์ (Netlify + Turso) + โดเมนของร้าน
